## Must fix
1. **Flow builder clipped at 375px** - Reference: image_original4 (flow builder) - tree fits the canvas. Build: `verify/critique/app/mobile-app-flow-full.png` - the card is 343px wide but its only grid track computes to 524px (`grid-template-columns: 524.36px`), so the tree grid is 484px, the "When a call comes in" pill ends at x=385 (viewport 375) and every row ends at x=521: 178px of each row and the sub-nav ("In…") are cut by the card's `overflow-hidden`. The sub-nav's four `shrink-0` items (scrollWidth 561px) set the track. Fix: `app/app/flow/page.tsx` line 87 `grid overflow-hidden lg:grid-cols-[250px_minmax(0,1fr)]` -> `grid grid-cols-[minmax(0,1fr)] overflow-hidden lg:grid-cols-[250px_minmax(0,1fr)]`, and add `min-w-0` to the `<aside>` on line 89.
2. **Activity column ratio is inverted** - Reference: image_original5 - list 279px / conversation 450px / caller 299px (27/44/29%); the gradient call card is the widest thing on screen. Build: `verify/critique/app/desktop-app-calls-viewport.png` - 340 / 332 / 360 (33/32/35%); the conversation column is the narrowest and the call card is 332px. Fix: `app/app/calls/page.tsx` line 67 `lg:w-[340px]` -> `lg:w-[300px]`; line 471 `xl:w-[360px]` -> `xl:w-[300px]` (gives ~300/432/300 at 1440). While there, make "Needs attention" not wrap inside the 340px segmented control (line 79: shorten to "Attention" or `whitespace-nowrap`).
3. **App frame: no topbar, and the sidebar's language row is missing** - Reference: image_original3/4/5 - a 50px topbar spans the whole frame (logo left; Download report / search pill + Import CSV + Create contact / Back to teams + Always Open right), a hairline under it, then a 175px sidebar whose bottom block is `En` (flag) / hairline / Help&Support, Mode / hairline / user card. Build: `verify/critique/app/desktop-app-viewport.png` - no topbar; the logo sits inside a 248px sidebar (17% of 1440 vs 12%); page actions sit beside the page title; bottom block has no language row and adds a sign-out icon. Fix: `components/app/Shell.tsx` - inside `.glass-frame` (line 71) wrap `aside` + `main` in a column: a `<header className="flex h-16 items-center justify-between border-b border-line px-6">` holding `<Logo/>` and a `TopbarActions` slot (context or portal) that pages fill instead of `PageHeader.actions` (dashboard "Download report", contacts search + Import CSV, billing buttons); remove the `Logo` link from the aside (lines 76-78); `w-[248px]` -> `w-[200px]`; above the `border-t` block on line 92 add a language row (`<button className="flex h-11 items-center gap-3.5 rounded-xl px-3 text-[15px] font-medium"><Globe className="size-[19px]"/> En</button>`) in its own `border-t pt-4` group.

## Should fix
1. **Wave rings are invisible** - Reference: image_original1 - dotted concentric wavy rings read across the whole viewport behind the head. Build: `verify/critique/landing/desktop-viewport.png` - none visible (a 3x-brightened crop shows only aurora); the rings canvas paints 11,620 of 1,296,000 pixels (0.9%) because dots are 1.6px, ~20px apart (`dots = base / 3.2`) and alpha 0.12-0.34. Fix: `components/head3d/WaveRings.tsx` line 47 `Math.floor(base / 3.2)` -> `Math.floor(base * 1.1)` (~6px spacing), line 57 `1.6, 1.6` -> `2.2, 2.2`, line 48 alpha floor `0.12` -> `0.28`.
2. **Portrait plane reads as a rectangle; shoulders cut flat** - Reference: image_original1 - the head floats, neck cables dissolve into black. Build: `verify/critique/landing/desktop-viewport.png` - the jacket is cropped by a straight line at the canvas bottom (y=719 CSS; luminance 16 -> 26 across the edge at x=500) with the subtitle directly under it; at 375 (`landing/mobile-viewport.png`) the whole canvas box is a darker rectangle with edges at y~160 and y~545 (luminance steps 42->37 and 11->18 at x=10, 30 and 355). Cause: `components/head3d/Portrait3D.tsx` line 62 `subject = smoothstep(0.06, 0.2, vD)` leaves the keyed backdrop partly opaque, and the 3.7-unit plane extends past the 2.79-unit visible height so the bottom fade (line 63) is clipped. Fix: `smoothstep(0.16, 0.30, vD)` on line 62, and in `components/marketing/Hero.tsx` line 45 add `[mask-image:linear-gradient(to_bottom,black_55%,transparent_100%)]` to the HeadScene wrapper.
3. **Bottom-right tiles are not tiles** - Reference: image_original1 - two 59px upright rounded-square tiles (figma, Ae) mirror the three on the left; no tile is rotated. Build: `landing/desktop-viewport.png` - right cluster is a 126x56 "Talk to it" pill + a 45deg-rotated 56px "Demo" tile; the left cluster's middle tile is also rotated. Fix: `components/marketing/Hero.tsx` lines 76-91 - render both right-hand controls as `Tile` (size-14 rounded-2xl, mic icon / dashboard icon, `aria-label`); drop the `diamond` prop on lines 60 and 87.
4. **About + process split ratio and circle anatomy** - Reference: image_original2 - pill column 414px (29% of 1440); the statement starts at x=414 with a 936px measure and the six circles start on the same x; inside a 210px circle the icon sits 60px above centre and the label 60px below (+-29%).
